# Architecture Decision Records

Здесь фиксируются решения, которые дорого менять и о которых спросят на защите:
выбор архитектуры, лицензионно значимый выбор библиотек, модель разграничения доступа,
обращение с платёжными данными.

Записи не редактируются задним числом. Если решение пересмотрено — пишется новая запись
со статусом «Принято», а старая переводится в «Заменено ADR-XXXX».
