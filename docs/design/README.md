# Макет проекта ZeldaArena

Макет выдан преподавателем в виде готового HTML-шаблона.
Этот файл — карта макета. Читать его в начале Фазы 5 перед любой вёрсткой.

## Структура

| Путь | Что это | Читать? |
|---|---|---|
| `pages/*.html` | Разметка экранов шаблона, по файлу на экран | **Да** |
| `assets/css/style.css` *(уточнить точное имя)* | Авторские стили: цвета, шрифты, отступы | **Да** |
| `assets/css/*.min.css`, `bootstrap*`, `boxicons*`, `flaticon*` | Вендорские библиотеки | Нет |
| `assets/js/*` | Скрипты шаблона: слайдеры, анимации, меню | Нет |
| `assets/fonts/*` | Бинарные шрифты (`.woff`, `.woff2`, `.ttf`) | Нет, только копировать |
| `assets/img/*` | Изображения и иконки шаблона | Нет, только копировать |
| `design-system.md` | Извлечённые токены. Создаётся в Фазе 5 | **Да, после создания — основной источник** |

## Экраны, которых в макете НЕТ

Собираются из тех же токенов и компонентов, что и остальные:

- `/tournaments`, `/teams`, `/players` — списки с фильтрами (за основу взять сетку карточек из `shop.html`)
- `/teams/create`, `/account/my-team` — создание и управление своей командой
- `/account`, `/account/subscription`, `/account/security` — личный кабинет, тарифы, безопасность
  (за основу взять формы со страницы входа и внутренние блоки шаблона)
- `/orders` — история заказов (за основу взять табличные блоки шаблона)
- Area `Admin` — собственный макет `_AdminLayout` на тех же токенах
- Страницы ошибок 400/401/403/429/500 — по образцу `404.html`

## Ограничения и договорённости

- Обязательных цветов и шрифтов преподаватель не задавал. Единственный источник истины —
  сам шаблон в `assets/`: палитра, типографика и отступы извлекаются из него и фиксируются
  в `design-system.md`. Придумывать свои цвета не нужно.
- Шрифты шаблона: `Vermin Vibes` (заголовки), `Boxicons` и `Flaticon` (иконки) — переносятся
  в `wwwroot/fonts` как есть.
- Экраны, которых в макете нет, собираются из тех же токенов и уже созданных компонентов.
  Новые визуальные решения вводить только там, где без них не обойтись.
